# CROAKDOWN

Swamp-mystic **embodied tower-defense** co-op game: you are a frog warden who fights
in the arena (Brotato feel) and plants living swamp towers (BTD6 brain). Shared-screen
2P — keyboard + DualSense.

- Port: **5126** (`--strictPort`, registered in `PROJECTS.md`)
- Front door: `GYAT.md` (goal-lock, research, must-beat bar, brief, status)
- Cold-session resume: `SESSION_START.md`

Run: `npm run dev` → http://localhost:5126
