# Core Loop

> Part of the [[00 START HERE|CROAKDOWN bible]] · updated 2026-07-07

Ian-verbatim shape: *"Start wave → fight huge swarms → collect XP → level-up choice → shared shop → repeat. Bosses every few waves. Simple. Fast. Readable."*

## The minute-to-minute loop (combat)

1. **Read** — spawn telegraphs and silhouettes announce what's coming ([[Enemy Design Standards]])
2. **Position** — hop, dash-hop, tongue-pull yourself or enemies ([[Movement and Controls]], [[Giant Tongue]])
3. **Swing** — manual, buffered, chainable melee ([[Combat System]])
4. **Savor** — hitstop, launch, collision, splatter, essence burst ([[Game Feel Standards]])
5. **Collect** — essence drops pull in a small magnet radius; the body pays for the economy (walk to wealth)

The loop is fun with zero rewards — that's the [[Quality Gates|Swing Test]]. Rewards amplify; they never carry.

## The wave loop (~60–100 s + breather)

- **Wave runs** until its spawn budget is dead ([[Waves and Pacing]])
- **Level-ups** during combat hard-pause into a 3-card stat pick (co-op: simultaneous per-player picks, see [[Co-op Design]])
- **Wave clear** → essence tally → **shared shop**, hard-paused, untimed ([[Shop and Economy]])
- **Next wave starts** on both players' ready input (hold = commit; release cancels — a diegetic croak-together, zero UI text)

## The run loop (25–35 min)

- 20 waves. Rule-breaker enemies enter on a fixed weirdness schedule; stats ramp separately ([[Waves and Pacing]])
- **Bosses at 5 / 10 / 15 / 20**: [[Drowned King]] → [[Mother Mosquito]] → [[Bog Leviathan]] → [[The Bloom]]. Family elites at 4 / 8 / 12 / 16
- Boss kill → **Bloom Chest ceremony** — the game's single most-polished reward moment ([[Waves and Pacing]])
- The frog **evolves visibly** across the run — weapon and body transform, never just numbers ([[Progression and Evolution]])
- Fail state: all frogs dead (co-op: double-KO after bleed-out rules, [[Co-op Design]]). No base to defend — the TD Heartbloom fail state is dead
- Run end (win or die) → run report as a *picture*: the arena's accumulated carnage with stats overlaid — the battlefield IS the scoreboard ([[VFX Standards|permanence]])

## The meta loop (post-v1, designed-for now)

Unlockable frogs, weapons entering the shop pool, danger pips (0–3 difficulty at run start, Brotato pattern), and secrets that persist as discoveries ([[Secrets and Discoveries]]). No power meta-progression that invalidates the Swing Test — combat is fun at zero unlocks, forever.
